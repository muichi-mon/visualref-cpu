Background

Why not just search with text?

Keyword search works well until the image in your head is hard to put into words. VisualRef is built for that gap: rather than relying only on a text query, you can steer the results directly — telling the system which images are close, which parts of an image matter, and which don't.

This study looks at how people actually use those tools when searching for a specific target image, and how the experience feels along the way.

Key terms

Vocabulary you'll see throughout

Image retrieval
The process of finding a specific image, or set of images, that matches your search goal.
Query
What you give the system to start a search — text, an image example, or another kind of input.
Search iteration
One full cycle of searching and refining. Finding a target image may take several.
Relevance feedback
Marking whether a result is useful or not useful for what you're trying to find.
Bounding box
A rectangle you draw around a region of an image to point at exactly what matters.
Visual search
Searching by an image's content or visual characteristics, rather than by words alone.
Instructions

Your task, each round

A target image is shown briefly, then hidden. From there:

  1. 01Look at the target image while it's shown — it disappears after a short time.
  2. 02Use VisualRef to search the image collection for that exact image.
  3. 03Use any combination of the available features to refine your results.
  4. 04Once you've found it, mark the task as complete.
  5. 05Answer a short questionnaire about that round before moving on.

There's no single correct strategy — use the system as naturally as you would on your own, and do your best if a target proves hard to find before moving on.

Using VisualRef

Four tools, used in any combination

Initial search

Start the retrieval process from the search interface, with a text description.

Bounding boxes

Highlight the specific region of a result that's important — or unimportant — to your search.

Relevant / irrelevant feedback

Flag which results are helping and which are getting in the way.

Query refinement

Feed what you've marked back into the system to sharpen the next set of results.

What we measure

This evaluates the tool, not you

Nothing here is a performance test. Over the course of the study we log:

  • Task completion time
  • Search interactions
  • Number of search refinements
  • Retrieval success
  • Your questionnaire responses

All data is analyzed anonymously and used only for research purposes.
